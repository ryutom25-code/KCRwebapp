# KCR Campus

スマートフォンを中心に利用する来校・ポイント管理アプリ。PCではサイドバーと広い一覧を使用します。既存のHTMLルートとSupabaseのデータ契約を保ち、16画面を共通デザインシステムで再構築しています。

## 起動

ビルド・npmインストールは不要です。

```sh
python3 tests/preview_server.py --port 8766
```

- 利用者画面: http://127.0.0.1:8766/home.html
- 管理画面: http://127.0.0.1:8766/admin/index.html
- 新規登録: http://127.0.0.1:8766/signup.html

通常起動では `js/env.js` の実際のSupabaseに接続します。管理画面はログイン不要、利用者のポイント・プロフィール操作はログインが必要です。カメラはHTTPSまたはlocalhostで使用してください。

## 画面と機能

| 画面 | 機能 |
| --- | --- |
| ホーム | プロフィール・所持ポイント・お知らせ・各機能への移動 |
| ログイン / 新規登録 | メールとパスワード、確認メール、送信状態・エラー表示 |
| プロフィール | 登録・既存情報の編集 |
| チェックイン | QR読み取り・同じ学科は60分に1回のポイント獲得・次回可能時刻の表示 |
| 学科クイズ | 学科・セット選択、問題回答、正解済み問題の除外 |
| 景品交換 | 景品画像・必要ポイント・不足ポイント、交換QR読み取り |
| ポイント履歴 | 獲得と消費の一覧 |
| 学科情報 | 5学科の案内・クイズへの移動 |
| 管理ダッシュボード | 当日チェックイン・交換件数 |
| 来校履歴 | 学科・学校・学年による絞り込み、日時順、編集・削除、CSV |
| 景品交換履歴 | exchange_logs_viewの全件取得、氏名・学校・景品の検索、CSV、景品ランキング、件数・消費ポイント合計 |
| 景品管理 | 登録・編集・削除、画像圧縮・アップロード、画像の拡大表示 |
| イベント管理 | 登録・編集・削除、開催日・NEW設定 |
| クイズ管理 | 学科別4問セットの登録、既存セット・問題の編集と削除 |
| QRコード発行 | 学科・交換ブース・イベントQRの生成と印刷 |

ホームの4メニューは、左上が学科クイズ、右上がミニゲーム、左下が学科説明、右下がポイント交換。ミニゲームは指定により `home.html` へ戻る仮リンクです。QR読み取りボタンはポイントカード内の履歴リンクの上にあります。

## 構成

- `css/style.css`: 色・余白・部品・レスポンシブ・印刷の共通定義
- `js/ui.js`: 共通ナビゲーション、パスワード表示、通知・確認ダイアログ、キーボード操作
- `js/common.js`: 無害化、CSV、全件取得、RPC、重複送信の識別
- `js/*.js`: 利用者画面のデータ取得・処理
- `admin/js/*.js`: 管理機能
- `supabase/`: 既存DBの前提と移行SQL。詳細は `supabase/README.md`

プロフィール保存・チェックイン・クイズ回答・交換・クイズセット登録は既存のRPCを使用します。これらは対応するDB関数が必要です。QR・交換のエラー解消とクイズ編集・削除の追加に合わせ、第4移行を本番DBへ適用しました。詳細は `supabase/README.md` を参照してください。

## 検証

```sh
node tests/regression.cjs
```

本番に書き込まないUIテスト用プレビュー:

```sh
python3 tests/preview_server.py --fixtures --port 8765
```

`--fixtures` ではHTTPレスポンス内だけでSupabaseとカメラをスタブに置換します。通常のHTML・JSと本番の接続設定は書き換えません。

```sh
# 一時プロファイルのChromeを別プロセスで起動
# --headless --remote-debugging-port=9333 --remote-allow-origins=http://localhost:9333
python3 -m pip install websocket-client
python3 tests/ui_regression.py
```

16画面×390px/1440px、JavaScript例外、可視画像、横はみ出し、検索・編集・クイズ・QR・パスワード表示を検証します。画面キャプチャは `/tmp/kcr-ui-previews` に生成します。実機でのカメラ許可と本番の登録・交換は、テストデータでの最終確認が必要です。

同一学科の来校ポイントは、利用者ごとに前回の成功から60分に1回です。別学科は続けて獲得できます。`PT` と `welcome:PT` などの別表記も同一学科として扱います。第5移行でDB側に制限を設定済みです。イベントQRと景品交換のルールは変更していません。
